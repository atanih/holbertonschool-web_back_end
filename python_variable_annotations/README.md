# Python - Variable Annotations

Proyecto sobre anotaciones de tipos en Python 3, firmas de funciones,
duck typing y validación de código con mypy.

## Tareas

| Archivo | Descripción |
|---|---|
| 0-add.py | Suma de dos floats |
| 1-concat.py | Concatenación de dos strings |
| 2-floor.py | Floor de un float |
| 3-to_str.py | Representación en string de un float |
| 4-define_variables.py | Variables anotadas |
| 5-sum_list.py | Suma de una lista de floats |
| 6-sum_mixed_list.py | Suma de una lista mixta int/float |
| 7-to_kv.py | Tupla string + cuadrado como float |
| 8-make_multiplier.py | Función que devuelve una función |
| 9-element_length.py | Duck typing de un iterable |
