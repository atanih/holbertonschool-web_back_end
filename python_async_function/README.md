# Python - Async

Proyecto sobre ejecución asíncrona en Python 3.8 con `asyncio`:
sintaxis `async`/`await`, corutinas concurrentes, tareas y el módulo `random`.

## Tareas

| Archivo | Descripción |
|---|---|
| 0-basic_async_syntax.py | Corutina `wait_random` con retardo aleatorio |
| 1-concurrent_coroutines.py | `wait_n`: n corutinas concurrentes, delays ordenados |
| 2-measure_runtime.py | `measure_time`: mide el tiempo medio de ejecución |
| 3-tasks.py | `task_wait_random`: devuelve un `asyncio.Task` |
| 4-tasks.py | `task_wait_n`: igual que `wait_n` pero con tasks |
