# Python - Async Comprehension

Proyecto sobre generadores asíncronos, comprensiones asíncronas y
anotación de tipos para generadores en Python 3.8.

## Tareas

| Archivo | Descripción |
|---|---|
| 0-async_generator.py | Generador asíncrono que emite 10 números aleatorios |
| 1-async_comprehension.py | Recolecta 10 valores con una async comprehension |
| 2-measure_runtime.py | Mide el runtime de 4 comprensiones en paralelo |
